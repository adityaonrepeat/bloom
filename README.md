## About Bloom

Bloom is a mental health support platform created to ensure that no one has to face their emotional struggles alone.

The platform helps people:

- Connect with others experiencing similar emotions
- Share feelings anonymously in a safe environment
- Receive empathetic AI-powered support
- Build healthier emotional habits through journaling and mood tracking
